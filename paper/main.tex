\begin{abstract}
	
	Engineering forecasting systems require reliable mechanisms for deciding when a
	learned predictor is suitable for deployment. Validation-only selection can be
	misleading under temporal dependence, nonstationarity, and increasing model
	complexity.
	
	This paper proposes an auditable complexity-controlled forecasting framework
	that combines linear and first-order Takagi--Sugeno (TSK) predictors with
	sequential PAC-Bayesian risk assessment for deployment-oriented model selection.
	
	Each candidate predictor is represented through an explicit structural
	description including model family, lag configuration, regularization settings,
	fuzzy rule structure, and realized rule count. A chronological prior construction
	and sequential certification procedure quantify the trade-off between empirical
	performance and structural complexity. A frozen deployment gate combines risk
	certificates, validation margins, and temporal stability criteria before
	replacing a seasonal baseline.
	
	The framework is evaluated using synthetic temporal processes and independent
	electricity-load forecasting tasks from PJM regional datasets. Results show that
	complexity-controlled selection can reduce TSK structural complexity without
	sacrificing competitive forecasting performance. When simpler predictors provide
	stronger evidence from the data, the framework retains them rather than forcing
	more complex models.
	
	The proposed approach provides an auditable decision layer for trustworthy
	engineering forecasting systems, complementing predictive accuracy with
	transparent risk and complexity assessment.
	
\end{abstract}
